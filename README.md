## How it works

`main.py` (Python 3.13, standard library only) copies the pre-rendered
`entry.png` (1024x1024) into `$MAKEFUN_OUTPUT_DIR`. The image was drawn
deterministically with Pillow at build time — two renders are byte-identical
— and the entry program itself needs no third-party packages and no network,
so it runs cleanly in the grader's stock Python image.
